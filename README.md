# Redux Toolkit Shopping Cart (React + TypeScript)

## Chạy trên Visual Studio Code

1. Giải nén ZIP.
2. Mở VS Code → File → Open Folder... → chọn thư mục `redux-shopping-cart`.
3. Mở Terminal → New Terminal.
4. Chạy:
   ```bash
   npm install
   npm run dev
   ```
5. Mở địa chỉ local Vite hiện trong terminal (thường là `http://localhost:5173`).

Kiểm tra build:
```bash
npm run build
```

Ứng dụng gọi API công khai DummyJSON. Cần có kết nối Internet để tải danh sách sản phẩm. Giá VND, thuế và vận chuyển chỉ là dữ liệu minh họa; thanh toán chưa tích hợp.
